## Lunar Linux

A source-based Linux distribution. Every package is compiled on your machine, with the options
you pick, and one tool keeps it simple: `lin nano` downloads, builds and installs nano and its
dependencies.

- **Website and documentation:** [lunar-linux.org](https://lunar-linux.org/)
- **Chat:** `#lunar` on [Libera.Chat](https://web.libera.chat/#lunar)

### Repositories

| | |
| --- | --- |
| [lunar](https://github.com/lunar-linux/lunar) | The package manager: `lin`, `lrm`, `lvu` and `lunar` |
| [moonbase-core](https://github.com/lunar-linux/moonbase-core) | Modules (build recipes) for the core system, plus [other](https://github.com/lunar-linux/moonbase-other), [xorg](https://github.com/lunar-linux/moonbase-xorg), [kde](https://github.com/lunar-linux/moonbase-kde), [gnome3](https://github.com/lunar-linux/moonbase-gnome3), [gnome](https://github.com/lunar-linux/moonbase-gnome), [xfce](https://github.com/lunar-linux/moonbase-xfce) and [efl](https://github.com/lunar-linux/moonbase-efl) |
| [lunar-iso](https://github.com/lunar-linux/lunar-iso) | Builds the installer ISO images |
| [lunar-web](https://github.com/lunar-linux/lunar-web) | The website and documentation |

### Contributing

Module updates and new modules are pull requests to the moonbase repositories. Questions and ideas
are welcome in `#lunar`.
